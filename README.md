Dieses Projekt ist Teil einer SEW-Aufgabe. Man soll mittels dem MVC-Modell ein Spiel bauen, wo man die selbe Zahl wie ein Computer rät.
Wenn man dieselbe Zahl rät, erhält man +10 Punkte. Eins rüber/drunter +5, sonst -10.
Das Ziel ist es 100 Punkte zu erreichen und somit zu gewinnen.
Verloren hat man, wenn man 0 oder weniger Punkte hat.
